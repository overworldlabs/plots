# README

Welcome to the official documentation for **Plots**.

Plots is a grid-based plot management plugin for Hytale focused on controlled building gameplay and predictable server administration.

## What You Get

- Full plot lifecycle: claim, auto-claim, rename, delete, trust/untrust, list/info.
- Plot structure controls: flags and merge/unmerge workflows.
- Protection stack: build/interact/liquid/PvP controls + BuilderTools protections.
- Optional integrations: economy providers, Hylograms, SQL persistence.
- Localization and API support for custom server ecosystems.
