# What is Plots?

Plots is a plot-world management plugin for Hytale servers.  
It provides a strict, configurable system for allocating build space to players while keeping moderation, protection, and expansion workflows straightforward.

## Core Scope

- **Plot ownership workflows:** claim, auto-claim, rename, delete, trust/untrust.
- **World structure controls:** road-based grids, merge/unmerge between adjacent owned plots.
- **Protection enforcement:** roads and foreign plots are protected; liquids and interaction are validated.
- **BuilderTools safety:** protected usage for standard operations and advanced flows (extrude/scripted brush).
- **Server integration:** optional economy charging, SQL persistence, translation bundles, and plugin API.
